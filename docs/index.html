Historical student project / new interactive example

A ball, a trampoline, a target

Launch a ball, change the trampoline angle, and try to reach the target. This small browser game revisits the cannon-and-trampoline interaction described in the students’ iPad game report.

New independent browser game · New vector artwork and simplified physics. This is not a port of the students’ Cocos2D/Box2D code, levels or artwork.
